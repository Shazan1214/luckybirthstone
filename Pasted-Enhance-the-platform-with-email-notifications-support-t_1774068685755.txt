2. SUPPORT TICKET SYSTEM
----------------------------------

Create a support system for users and admin.

----------------------------------
USER SIDE
----------------------------------

Add "Support" section in user dashboard.

User can:
- Create ticket

Fields:
- ticket_id
- user_id
- subject
- message
- status (open, in_progress, resolved)
- created_at

Endpoints:
- POST /support/tickets (create ticket)
- GET /support/tickets/:user_id (view own tickets)

----------------------------------
ADMIN SIDE
----------------------------------

Admin panel section: "Support Tickets"

Admin can:
- View all tickets
- Filter by status
- Respond to ticket
- Update status

Add responses:

ticket_responses:
- ticket_id
- admin_id
- message
- timestamp

Endpoints:
- GET /admin/tickets
- POST /admin/tickets/respond
- PUT /admin/tickets/status

----------------------------------
EMAIL ALERTS FOR SUPPORT
----------------------------------

- When ticket created → notify admin
- When admin replies → notify user
